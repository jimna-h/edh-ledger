Data relay settings public relays are flaky — set your own for reliability

Browsers block this page from calling Archidekt's API directly (CORS), so every request goes through a relay that fetches Archidekt's response and hands it back with permission attached. Public ones (codetabs, allorigins) are used automatically as a fallback, but they rate-limit and go down without notice. A relay you host yourself is instant and free — five minutes on Cloudflare's free tier, no credit card:

  1. Go to workers.cloudflare.com and create a Worker (any name).
  2. Replace the default code with the snippet below, then click Deploy.
  3. Copy the worker's URL (looks like https://your-worker.your-name.workers.dev), paste it above as https://your-worker.your-name.workers.dev/?url={url}, and click Save.
export default {
  async fetch(request) {
    const target = new URL(request.url).searchParams.get('url');
    if (!target || !target.startsWith('https://archidekt.com/')) {
      return new Response('Only archidekt.com is allowed', { status: 400 });
    }
    const upstream = await fetch(target, { headers: { 'User-Agent': 'Mozilla/5.0' } });
    const body = await upstream.text();
    return new Response(body, {
      status: upstream.status,
      headers: {
        'Content-Type': upstream.headers.get('Content-Type') || 'application/json',
        'Access-Control-Allow-Origin': '*'
      }
    });
  }
}

This worker only ever forwards requests to archidekt.com, so it can't be used as an open proxy for anything else.

Paste an exported decklist use this if live loading keeps failing

Archidekt's server appears to challenge/block automated requests (that's why the relays above keep getting HTML instead of JSON — happens even from a dedicated relay). This sidesteps it: on the deck page, open More → Export, choose the Text format (leave categories on, if offered), copy the result, and paste it below. Card details (type, color, mana value) are then looked up from Scryfall's public API. A bare list of quantities and names works too — you'll just lose category tags and the commander star.
